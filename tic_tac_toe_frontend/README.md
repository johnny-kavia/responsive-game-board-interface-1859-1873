# Tic Tac Toe Frontend (React)

Responsive, modern light-themed Tic Tac Toe with:
- Two-player turns (X then O)
- Win/draw detection
- Winning line highlight
- New round (keeps scores)
- Reset scores (full reset)

## Run
```bash
npm install
npm start
```

The dev server runs on port 3000 by default. To change, set `PORT` (see `.env.example`).
